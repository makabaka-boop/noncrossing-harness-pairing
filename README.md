# 圆形测试治具非交叉完美匹配 API

纯后端服务（Python 3.12 + FastAPI）：给定按圆周顺序排列的端口与允许连接的无向边
（带 `0..10^9` 整数费用），用**区间动态规划**求出覆盖全部端口、导线互不遮挡
（弦不交叉）的**最小总费用完美匹配**，并输出一份确定的接线证书。

只挑每个端口最便宜的伙伴（贪心）可能把奇数个端口封在弦内而无法收尾——本服务对
全部可行非交叉布局做区间 DP 取全局最优。

## 运行

```bash
docker compose up --build
# API:  http://localhost:8000
# 文档: http://localhost:8000/docs
```

本地开发：

```bash
pip install -r requirements-dev.txt
uvicorn app.main:app --reload
pytest
```

## 接口

### `POST /layout`

请求：

```json
{
  "ports": ["A", "B", "C", "D"],
  "edges": [
    {"u": "A", "v": "D", "cost": 2},
    {"u": "B", "v": "C", "cost": 7},
    {"u": "A", "v": "B", "cost": 100}
  ]
}
```

* `ports`：2–120 个**唯一、非空、ASCII** 端口 id，顺序即圆周顺序（下标从 0 开始）。
* `edges`：允许的无向边，`cost` 为 `[0, 10^9]` 的整数。

成功响应（200，无部分配对）：

```json
{
  "status": "OK",
  "index_base": 0,
  "total_cost": 9,
  "matching": [["A", "D"], ["B", "C"]],
  "chords": [
    {"pair": ["A", "D"], "indices": [0, 3], "cost": 2,
     "separated_interval": {"lo": 1, "hi": 2}},
    {"pair": ["B", "C"], "indices": [1, 2], "cost": 7,
     "separated_interval": {"lo": null, "hi": null}}
  ]
}
```

* `matching` / `chords` 按配对下标升序整体排序。
* `separated_interval` 是该弦沿下标方向**严格夹在两端之间**的闭区间 `[lo, hi]`；
  相邻端口之间无端口，返回 `{"lo": null, "hi": null}`。

不存在可行非交叉布局时：

```json
{"status": "NO_LAYOUT"}
```

### 校验失败 → HTTP 422

奇数端口数、端口数越界、端口 id 重复/非 ASCII/空、自连、引用未知端口、重复边
（含反向重复）、费用越界或非整数、字段缺失/多余/类型错误，统一返回 422。

### `GET /health`

返回 `{"status": "ok"}`。

## 算法（区间 DP）

端口按圆周顺序编号 `0..n-1`。弦 `(l,k)` 把盘面分成弦内 `[l+1,k-1]` 与弦右侧
`[k+1,r]` 两部分；非交叉完美匹配中两部分必须各自内部配对，因此 `k-l` 必须为
奇数（两侧都是偶数个端口）。

对偶数长度的区间 `[l,r]`：

```
dp[l][r] = min  cost[l][k] + dp[l+1][k-1] + dp[k+1][r]
            k  (l<k≤r, (k-l) 为奇数, (l,k) 允许)
```

空区间费用为 0；候选边不存在或子区间无解则跳过。复杂度 O(n³)，n=120 完整图约
0.1 秒。

**字典序决胜**：每对端点按下标升序书写 `(i,j), i<j`，再把所有配对整体排序。
费用并列时选择该配对序列字典序最小者。由于子解位于互不相交的下标区间，各状态
保存自身字典序最小子解、比较完整候选序列即可得到全局字典序最优。

## 测试

`pytest` 对小圆环（n=2..10，双阶乘种完美匹配）**枚举全部匹配**与区间 DP 对拍，
覆盖：

* 稀疏图（缺边导致 `NO_LAYOUT`）与稠密图；
* 零成本（大量并列）与少值费用（大量并列时的字典序决胜）；
* 贪心挑最便宜伙伴导致端口无法收尾的反例；
* API 层全部 422 场景、`NO_LAYOUT`、弦分隔区间、n=120 性能与证书结构
  （覆盖全部端口、配对规范排序、互不交叉、费用合计准确）。
